the ivy programming language

ivy

Ivy is a statically typed functional programming language: friendly enough for beginners, robust enough for experienced programmers. Built to be inspected, reasoned about, and trusted.

Ivy draws from the golden age of computing: UNIX, Plan 9, Haskell, IBM.

Simple things should be simple. Complex things should be possible. Ivy currently supports basic functional programming constructs: functions as first-class citizens, algebraic data types, Hindley-Milner type inference, and friendly error messages.

Planned in the future: type classes, refinement types, a more robust REPL, and a faster backend. Stay tuned!

Source code: github.com/gtr/ivy
